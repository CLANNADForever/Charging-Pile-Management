# Resume prompt

Run `scripts/resume_from_snapshot.sh`. Trust the root snapshot only for active selection, then rebuild status from OpenSpec CLI, tasks, local snapshot, footprint, Integration plan/report and Evaluation. Read the report whenever status lists it, and never assume its candidate mapping stayed fresh after a source or planning edit. If active is null, stale, archived, its evidence family needs explicit upgrade, or its implementation base is invalid, stop and request an explicit selection or recovery instead of guessing.
