# 2026-09-05 · 三件事：后端站桩数据/列表 · C 端找桩页 · 最简模拟器

## 已做
- **默认真后端**：main.cpp 用 HttpUserService（需先启动后端）。
- **Thing1 后端数据与列表**：
  - Store 建 stations/devices 表，首次启动 seed 3 站 9 桩（望京/中关村/亦庄）。
  - 接口：`GET /api/stations`、`GET /api/stations/{id}/devices`（curl 可拉）。
- **Thing2 C 端找桩页**：
  - 抽共享 `HttpJsonClient`(同步 GET/POST)；`IStationService`+`HttpStationService`。
  - 登录→个人中心"周边找桩"按钮→找桩页拉列表展示（站名/地址/空闲/单价）。
- **Thing3 最简模拟器**：
  - `src/simulator`（纯 C++ 无 Qt）：TCP 连后端，周期心跳 JSON-lines。`ncs_simulator [host] [port] [间隔] [起始桩] [桩数]`
  - 后端 `BackendApp.startSimListener(port)` 独立线程监听，走 `IHeartbeatSink`（现为 LogSink 计数）；适配点已留。
- 测试：3 套全绿（新增 sim TCP 收 3 心跳断言）。

## 运行示例
```bash
build/src/backend_server/ncs_server /tmp/ncs.db 8080 18000 &
build/src/simulator/ncs_simulator 127.0.0.1 18000 2 1 9 &
# 后端 stdout 会打印 [sim] hb device=...
curl http://127.0.0.1:8080/api/stations
build/src/client_user/ncs_user            # ssh -X 看找桩页
```
